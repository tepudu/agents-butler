# Agents管家 / Agents Butler

Windows storage cleanup for AI workflows, with reviewable cleanup candidates and recovery for supported cleanup operations.

面向 AI 工作流的 Windows 存储清理工具：审阅缓存与旧文件候选，并为支持的清理操作提供恢复功能。

**Current release: [0.2.2 Alpha](https://github.com/tepudu/agents-butler/releases/tag/v0.2.2-alpha) — 内测便携版。**

[Official website / 官网](https://agents-butler.tpoad.com/) · [Downloads / 下载与版本说明](https://agents-butler.tpoad.com/download.html) · [Community / 邀请制社区](https://agents-butler.tpoad.com/community.html)

This repository distributes release packages and public product information. The application is closed source. GitHub-generated source archives do not contain the application; download the named Windows application ZIP from Releases.

本仓库用于分发软件包与公开产品说明。应用保持闭源。GitHub 自动生成的源码压缩包不含应用，请在 Releases 中选择 Windows 应用 ZIP。

Model classification, translation, attachments, third-party sign-in and online signed rule updates are not enabled in this alpha. Community access is invite-only. Full project-reference detection and some community synchronization improvements remain in progress. The portable build is not code-signed.

本次内测尚未开放模型判定、翻译、附件、第三方账号登录及在线签名规则更新；社区邀请制，完整工程引用判断及部分社区同步能力仍待完善。便携构建尚未代码签名。

GitHub downloads do not use the website's shared daily allowance. Only self-hosted website downloads share the site-wide limit of 10 per Beijing day.

GitHub 下载不占用官网额度；仅官网自托管直下，全站每天合计限 10 次，按北京时间零点重置。
